# Reference Specification — AGENTROPOLIS Standards Film

## Job

Describe why the reference experience works before any motion is built.

## Experience target

The Standards site should feel like a cinematic entrance into a real institution inside the AGENTROPOLIS Intelligence Grid, not a dashboard and not a dense 3D control panel.

## First motion

The first readable event is environmental, not textual:

1. black / obsidian field;
2. cyan grid or captured spatial surface resolves;
3. central APS Registry structure becomes legible;
4. one line of language appears: **PROTOCOLS BECOME STANDARDS.**

No stack of cards should compete with the first frame.

## Camera grammar

Hero:
- slow forward approach / orbital drift;
- no rapid dolly;
- no constant UI labels in the environment;
- cyan denotes authorized/verified system state;
- red denotes risk, candidate state, denial or review;
- lime is reserved for standards-ready status.

Explainer:
- use one visual subject per beat;
- move from protocol → specification → conformance;
- show receipts / tests as evidence, not decorative HUD noise.

## Motion rhythm

- Hero loop: 12–18 seconds.
- First meaningful visual change: < 1.5 seconds.
- Major visual beats: approximately every 3–5 seconds.
- Text stays on screen long enough to read on mobile.
- Only active video plays. Offscreen video pauses.
- Reduced motion: static poster and no autoplay.

## Spatial / photogrammetry rules

Supported:
- captured multi-view reconstruction;
- 3D Gaussian Splatting;
- procedural 3D;
- browser-native WebGL/WebGPU.

Classical photogrammetry MUST NOT be claimed unless multiple calibrated views of the same subject or environment exist.

Canonical captured-spatial chain:
`Capture → Calibrate → Reconstruct → Clean → Measure → Validate → Render → Archive`

## UI rule

**Spectacle in the environment. Precision in the labels.**

The landing page carries only:
- identity;
- one sentence;
- two actions;
- one short governance line.

All dense inspection happens after deliberate interaction.

## Non-negotiable semantics

- Public repository ≠ standard.
- Identity ≠ authority.
- Execution ≠ evidence.
- Signal ≠ order.
- Presentation fidelity may change; standards meaning and authority may not.
