# Story — Standards Explainer

## One point

**AGENTROPOLIS turns proven operating protocols into public standards only after they are specified and independently testable.**

## Hero number

**43 public repositories are candidates, not 43 standards.**

## Three beats

### Beat 1 — Protocol
Show the Intelligence Grid as working infrastructure. A protocol is already doing real work inside a product or district.

Voice idea:
"AGENTROPOLIS starts with working protocols, not standards theater."

### Beat 2 — Specification
The environment simplifies. Product-specific decoration falls away, leaving the reusable contract:
identity, mandate, capability, execution, receipt.

Voice idea:
"We extract the rule that another system can implement without needing our UI, vendor, chain, or runtime."

### Beat 3 — Conformance
Show two independent nodes implementing the same contract and passing the same test vectors. Receipt closes the sequence.

Voice idea:
"A standard graduates when independent implementations can prove they conform."

## End frame

**ARCHITECTURE → PROTOCOL → SPECIFICATION → CONFORMANCE → INTEROPERABILITY**

Secondary:
**PUBLIC REPOSITORY = STANDARDIZATION CANDIDATE**
