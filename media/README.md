# Media drop zone

Approved release assets are placed here:

- `standards-hero.mp4`
- `standards-hero.webm`
- `standards-explainer.mp4`
- `standards-explainer.webm`

The page detects these files automatically. Until an approved render exists, the hero and explainer use lightweight fallbacks.

Do not label generated procedural imagery as photogrammetry. Classical photogrammetry requires an actual multi-view calibrated source set.
